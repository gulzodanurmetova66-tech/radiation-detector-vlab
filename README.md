
# Gas-Filled Radiation Detector Virtual Laboratory

An interactive educational simulation platform for
teaching radiation detector physics to medical students.

## Features
- Ionization chamber simulations
- Proportional counter simulations
- Geiger-Muller counter simulations
- Detector dead-time analysis
- Python and Wolfram Mathematica model verification
- Clinical problem-based learning scenarios

## Online Laboratory
https://gulzodanurmetova66-tech.github.io/radiation-detector-vlab/

## Research Status
Educational research prototype.
The models are not experimentally calibrated.
Not intended for clinical dosimetry or radiation-safety decisions.
